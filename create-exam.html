Import Questions

Supported formats: Plain Text (see format below), CSV (columns: question,choiceA,choiceB,choiceC,choiceD,correctIndex,category,solution), JSON (array of question objects), Word (.docx) (same structure as plain text)
Format: Each question separated by blank line. First line = question text. Next 4 lines = choices A-D. Line starting with "Answer:" or "Correct:" = correct index (0-3). Optional lines: "Category:" = category, "Solution:" = explanation shown on results.
